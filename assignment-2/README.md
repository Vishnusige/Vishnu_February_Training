# Assignment 2 - EdTech Management System (OOP)

A Command Line Interface (CLI) application demonstrating the four pillars of Object-Oriented Programming in Python.

## 🚀 Key Features
* **Encapsulation**: Used private attributes (`__name`, `__user_id`) to protect sensitive user data.
* **Inheritance**: Leveraged a base `User` class to derive specialized `Student`, `Mentor`, and `Admin` classes.
* **Polymorphism**: Overrode `display_details` methods to provide role-specific information dynamically.
* **Search Logic**: Implemented case-insensitive search and string cleaning for robust user enrollment.

## 🖥️ Usage
To run the management system:
`python q1.py`
